在 GitHub 上找软件，翻 Release、分辨版本、挑安装包，一套流程下来挺劝退。Komi Store 把这件事变简单了。

**官网**：https://github-store.org/

它是一个开源的跨平台应用商店，只收录 GitHub 上真正能装的软件，好处很实在。

## 找得快

自动扫描有安装包的仓库，过滤掉纯源码项目，热门、趋势、最新应用直接呈现在首页，不用再大海捞针。

## 下得准

自动识别你的设备，优先高亮匹配的安装包——Windows 的 EXE、macOS 的 DMG、Linux 的 AppImage/DEB、安卓的 APK，一键下载交给系统安装。

## 更新省心

记住你装过的应用，新版本上线自动提醒，每次更新还做签名校验，安全又省事。

## 信息全

README、更新日志、星标数据在一个干净界面里看全，选软件心里有数。

## 真跨平台

Android、Linux、macOS、Windows 全支持，多设备用户一套搞定。

官网直接打开就能用：https://github-store.org/

把在 GitHub 上"找软件"这件技术活，变成像逛商店一样轻松。
